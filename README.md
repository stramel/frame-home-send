# Send to Frame Home

The page your phone opens when you scan the code on Frame Home's
**Settings › Art › Add your images › From your phone** screen.

It sends to the [ntfy.sh](https://ntfy.sh) mailbox named in the link (the part after `#`),
which the TV is watching: either share links (Google Photos, Google Drive, Dropbox, image
addresses), and the TV downloads each full-size original itself, or small photos (ntfy.sh's
free tier takes files up to 2 MB), as they are. ntfy.sh deletes everything after 3 hours. This page holds no keys and stores nothing.

Published with GitHub Pages at https://stramel.github.io/frame-home-send/.
